## 工程（この順番厳守）
1. **素材の全数コンタクトシート化**（フェイシャル素材/ボディ素材/共通素材を全部見る。共通素材の店内・日常・清掃カットを忘れない）→ 各カットの明るさ(mean)をnumpyで実測
2. **原稿・キャプション → 彩さん確認**（確認ポイント①。AI画像を使うならこの時に候補シートも見せる）
   **⚠️提出前の必須セルフチェック＝「このサロンに行ってみたいと思う内容か」（2026-08-07彩さん指示・毎回）**：①「私のことだ」と思う入口があるか ②"このサロンに"行く理由（口コミで選ばれている/伴走/専門性のどれか）が入っているか ③通った後の未来の絵（生活シーン・言われるセリフ）が浮かぶか ④最初の一歩のハードルが低いか（診断型CTA）。1つでも欠けたら出さずに直す
3. **音声**：彩の声TTS（eleven_v3・API化済み `ELEVENLABS_API_KEY`）。**読み間違いはTTSに渡す語だけかな書きにして直す**（痩身→そうしん。テロップは漢字のまま）→ 文末の。境界だけで分割（読点の谷は使わない・字数÷声長6〜9字/秒で検算）→ 0.7秒間で再連結 → onset確定。イントネーションNGが出たら `narration-intonation-fix-sts` メモリの手順（録音をお手本にTTS複数テイク→F0相関で選ぶ。録音の直接挿入はNG＝声質が変わる）
4. **カット割り当て**：ナレーション各文に素材を当てる。テロップは冒頭フック含め全文＝声と完全一致（要約禁止・2026-08-08確定）。キャプション1行目も動画の冒頭と同じ情景に揃える。感情が動く画を優先（1c）・モデルは複数人混ぜる・BA≥6秒/1回/後半・**BA区間はテロップなし＝BAが主役（2026-08-08確定・フラッシュはテロップ下レイヤー）**・冒頭は0秒からフック（前置き禁止・**1枚目テロップはフェードインさせず0秒から完全表示**）・サロン雰囲気はブランド文に自然に挟む
5. **build_body.py を今回の onsets/カット/gamma に書き換えて実行**（gamma=log(mean/255)/log(142/255)で肌平均140に統一・白飛びはcurves前置き）
6. **build_final.py 実行**（タイミング定数：ダッキング=金文言区間・フラッシュ=BA直前・CTA開始）
7. **selfcheck.py 実行 → ALL PASS になるまで納品しない**（尺・全カット明るさ108-178・声同期・テロップ描画・セーフゾーン**y285-1635 かつ x40-950**＝右端はリールUIボタン帯なので素材が空白でも文字を置かない）
8. **表紙**：CanvaテンプレDAG-ADhUOmA（フェイシャル）/DAHO39cnB7w（痩身）をcopy→read-design(open_transaction)→replace_text（見出しだけ）→commit→export png原寸

## BA字幕の置き方（2026-08-17確定・毎回この順で決める）
1. BA素材の**上部テキストの横幅**を実測（例 x80-991）→ その内側に収める
2. **膝の位置**を実測（足先と頭頂から身長を出し、足先から身長×26%上＝膝）→ 字幕は**膝より下**（太ももはNG・ふくらはぎは被ってOK）
3. **中央は画面中央540**（左右対称の幅指定にする。素材幅で寄せると中央がズレる）
4. **2行まで**（3行は見にくい）・**行間は1.25以上**（詰めると文字が重なる）・入らなければサイズを下げる
5. 空き判定は**暗い画素(<150)の有無**で行う（白さで見ると白背景＋黒文字のラベルを空きと誤検出する）

## 今回の三大失敗と対策（再発防止）
- **AIっぽさ**：AI素材は「スマホで普通に撮れる画」だけ（シネマ光・金色逆光・過剰ボケ禁止／顔はぼかしでなくアングルで消す／鏡はフレーム外）。プロンプトに candid smartphone photo / flat daylight。生成後は顔・指・反射を原寸で目視
- **ルール無視**：作る前に memory の bemolle-reel-template.md を全文読み、工程4〜7で機械的に適用。「1個直すたびに場当たり修正」をしない＝直しはこのREADMEの工程に戻って該当段からやり直す
- **明るさ**：目視でなく必ず実測（選ぶ瞬間のフレームのmean）→gamma補正→selfcheckで最終実測。BA・彩さん承認済みの明るいカウンセリング素材(0011-0047)は触らない
